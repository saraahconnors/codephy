CodePhy — Lección piloto 01: Variables y tipos de datos

1. Extrae este ZIP en la raíz de tu carpeta python-fisica, sustituyendo los archivos existentes.
2. En VS Code abre la terminal: npm run dev
3. Visita la ruta local de Vite, después Aprender programación → 01 · Variables y tipos de datos.
4. No es necesario hacer git push.

Archivos modificados: src/App.jsx y src/App.css.
